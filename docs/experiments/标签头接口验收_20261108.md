# 标签头与Study聚合接口验收

日期：2026-11-08。项目：project_main。本批仅实现批准的C0/C1/H1/H2/H3接口及文档；没有启动正式比赛训练、读取比赛测试图像、提交或推送Git。原有其他本地修改保留。

## 已实现

- HEAD_C0：原共享Study注意力、10标签主头、0/3/7专家。
- HEAD_C1：共享Study注意力与10标签主头，关闭专家。
- HEAD_H1：每个标签独立选择Study中的图像，逐标签分类。
- HEAD_H2：ConvNeXt空间特征生成10个标签query表示，共享Study图像权重。
- HEAD_H3：空间query表示与逐标签Study图像权重组合，训练留待H1/H2筛选后安排。
- 新结构的视角/专家/MixUp互斥校验、空间头骨干限制、断点恢复与推理配置校验。旧配置缺省按历史linear路径处理。
- 独立Windows/Mac完整基线、明确HEAD配方、种子42/2027/3407配置生成及运行说明。

实现不增加第三方依赖。DINOv2加载器和自监督训练不在本批范围；下载链接仅作为后续通用骨干候选。
