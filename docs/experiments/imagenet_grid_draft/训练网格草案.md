# ImageNet通用权重训练网格草案 v0.3（CSV）

日期：2026-10-23。三种子：42、2027、3407。

本版以合并文件ImageNet训练网格汇总.csv为准，记录类型列区分阶段规则、实验和标签分工，UTF-8 BOM及CRLF，便于Windows Excel/WPS读取。PNG保留为上一版快照；CSV、JSON和接口文档为当前状态。

## 阶段推进

- S0 源码与基线复核：同步Windows实际训练源码，锁定A_exclude2和859个验证Study，建立A0。A0按统一15轮协议重跑，关闭早停，保留全部验证轨迹；历史R0只参考。晋级条件：A0三种子齐全，源码版本、完整配置和raw/EMA预测可追溯。
- S1 EMA与梯度裁切：以A0为固定对照，先完成EMA开关与clip开关2×2，再考虑decay。A0和C1/C2/C3统一15轮；C4是同次训练评估，不另算一次训练。晋级条件：候选和对照三种子配对比较，确认有效组合后保存S1配置。
- S2 学习率与训练预算：以S1确认配置为固定对照，分批改变warmup、LR、层衰减或有效batch。各批只改一个因素；总轮数对照会改变余弦轨迹。晋级条件：seed42筛选后补三种子；获益因素组合重验，保存S2配置。
- S3 分辨率：以S2确认配置为固定对照，比较192、224、256、320、384。训练验证同尺寸；默认有效Study batch16，显存不足减micro-batch并增累积。晋级条件：224有同协议对照；候选三种子比较AUC、耗时、显存，保存S3配置。
- S4 增强与正则化：以S3确认配置为固定对照，比较G0、增强、WD、drop path、dropout和预处理。每小批固定基线，候选值为绝对值；获益组合须重验。晋级条件：报告总体与逐标签AUC，三种子复核后保存S4配置。
- S5 类别不平衡与损失：以S4确认配置为固定对照，比较ratio、sqrt、unit、cap、focal、ASL及采样。posweight只从训练Study统计；强采样与强posweight先分开比较。晋级条件：结合逐标签阳性数与AUC，三种子复核后保存S5配置。
- S6 标签专家与结构：以S5确认配置为固定对照，先M1无专家消融与M2辅助权重，再考虑其他结构。三个MLP专家头已参与训练；AF0普通冻结头和AF1 AdaptFormer困难标签接口已实现，尚无真实训练成绩；M6-M9视角过滤与固定路由接口已实现，尚无真实训练成绩；新骨干使用各自合规通用权重。晋级条件：确认专家收益和部署体积；结构变化重新核对LR及正则，保存S6配置。
- S7 稳定性、推理与部署：冻结候选后做患者分层复核、确定性TTA、受限融合与导出。bootstrap不能消除调参偏差；Subject折分仅在train内；test不参与选择。晋级条件：实际部署文件符合500MB；固定全部选择后才可合并train+valid最终重训。

阶段内固定对照，42筛选后将候选与同协议基线补齐2027、3407。沿用已确认配置，不直接续训上阶段checkpoint。多因素组合后重新验证，没有稳定改善则保留原配置。历史R0只参考，关闭早停的统一15轮A0须重跑。

## 分辨率

I4=192、I5=224、I6=256、I1=320、I2=384。保留原I1/I2编号。五档均列三种子，训练验证同尺寸，默认有效Study batch16。224仅在完整配置、数据、源码和训练协议完全相同时复用旧结果，否则重跑。

## 按标签分工现状

已实现且参与训练：共享ConvNeXt主干、10标签主分类头、纵隔增宽/肺炎/肺部阴影三个MLP专家头。对应三个标签将主头与专家logit等权平均再sigmoid，专家辅助BCE权重0.5。AF0普通冻结头与AF1 AdaptFormer小样本专家接口已实现，但尚无真实训练成绩；现有专家收益也尚无消融证据，先做M1、M2。M6-M9视角过滤训练与固定路由接口已实现，需作为另一类方案单独训练和比较。

## 基准与判断约束

ConvNeXt-Base / convnext_base.fb_in22k；纯ImageNet-22K；A_exclude2；224；seed42/2027/3407；全量微调；AdamW；LR5e-4；15轮/warmup5；minLR1e-6；有效Study batch16；WD .05；layer decay .75；drop path .1；分类头dropout .2；G1；ImageNet归一化；E0；ratio posweight cap20；BCE；3专家辅助损失 .5；EMA .9998；clip 1.0。

- 范围：截至2026-10-23已检查的project_main/run。仅记录当前ImageNet通用权重路线，旧EVA-X结果不计入。未检索到的外部实验不视为未训练的证明。
- 已完成：5组有效单模型、1组验证融合。无有效epoch的G1目录不列为完成。所有分数都是固定859个Study的验证macro AUC，非比赛隐藏测试成绩。
- R0历史实际训练在第13轮结束，最佳第9轮；带patience4/min_delta .0005。H4最佳第16轮，实际warmup3、drop_path .1、EMA .9998；不要替换成先前口头建议。
- 准备门槛：训练入口已经接入EMA、AMP成功步、冻结/部分解冻、backbone.eval、EMA验证与恢复，并由73项自动化测试覆盖；真实Windows CUDA训练仍待执行。
- 新实验R0复核与C1/C2/C3构成EMA开关×裁切开关的2×2对照。统一最多15轮；机制比较建议关闭早停并保存全部轨迹。历史R0的0.80677只是已观测锚点，不能当作新协议已完成结果。
- 每行一个明确实验，不做候选值的全笛卡尔积。除标明的因素和相应名称/输出目录外，其余对齐对照基准。O6/O7是完整训练预算对照：改变总轮数也改变余弦轨迹，不声称只有多跑几轮。
- 优先级：P1先做，P2按结果补，P3保留候选。seed42先筛，候选用2027和3407配对复核；主基线三种子必须齐。三种子的预测平均AUC与单模型三种子均值±标准差要分别报告。
- 第一批建议：R0补2027/3407；C1/C2/C3和C4；O1/O2/O3；G0；I1；M1。不要直接启动全图所有训练。每组按Study算量，预计耗时以本机测量为准。
- 判定：报告macro AUC、逐标签AUC/阳性数、最佳轮次、训练曲线、三种子均值和样本标准差、AP/PA/LATERAL/LL/缺失视角分层结果（多视角Study可多组归属，不能简单加权重建总分）。少于两种子不报告稳定标准差。
- 重复筛选固定valid会使成绩偏乐观。V1仅在官方train内按Subject分三折，尽量兼顾多标签分布；这不是官方valid分数的同协议横比。V2按患者成组重采样，同一重采样用于成对模型，记录无正负样本时的处理；bootstrap不能消除调参选择偏差。
- 增强：G2是几何策略整体对照，若获益再分解旋转/平移/缩放。G3可能影响心脏位置/侧别相关信息。禁止把大幅裁剪胸部当作默认增强。CutMix保留为G6之后的候选，须先解决Study配对与标签mask传播。
- 类别不平衡：不能仅凭小样本给标签改成小样本架构。对照ratio/sqrt/unit与专家消融；强采样与强posweight不要未经对照同时叠加。标签平滑、SAM、SWA、ranking/AUC损失、U-Zero/U-Ones可在上述方案完成后另立协议，当前暂不排队。U策略仅在训练确有不确定标签时有意义。
- 新增EMA和冻结训练接口、ASL、MixUp、采样、专家路由、结构消融均已实现并有测试；本草案与CSV记录状态，真实训练仍待执行。
- 固定EMA从初始化副本起步；decay以成功optimizer更新次数为单位，不能按micro-batch。建议同时保存raw与EMA预测，后续推理只能调用被验证的对应权重。梯度裁切记录unscale后的裁切前norm与触发比例。
- 多视角：当前按Study多图注意力聚合。M6-M9提供视角过滤训练、推理和固定路由，缺少对应专家预测时回退基础模型，并输出覆盖率；真实专家尚未训练，最终还需确认比赛计时规则。四套完整Base专家预计不满足500MB；优先共享骨干/小头，或仅作为受控研究。
- 最终部署：单Base FP32纯权重约354MB，单Base FP16约177MB，双Base FP16约354MB，三Base FP16约531MB预计超限；以实际权重及必要配套文件解压后总量≤500MB核验。FP16文件导出和AMP训练是两回事。EMA仅导出选中一份。
- 规则：只用合规通用公开权重和赛方允许数据有监督训练。不做医学二次预训练/自监督续训；不使用外部医学数据；不以医学教师蒸馏替代来源要求。测试图仅验证脚本与最终推理，不拟合统计、阈值、融合权重或选择超参数。TTA须固定且确定性。
- 最后train+valid合并须先冻结全部选择，包括轮数、阈值和融合。合并后原valid不得再用于选checkpoint。predict与cost共用逻辑，声明精度，记录最终实际文件清单与来源许可。
- 所有新行均为待验证假设，不保证提高比赛AUC。该草案不是穷尽所有机器学习方法，而是覆盖当前数据、模型和比赛约束下值得分阶段验证的主要方向。
- v0.3以CSV为准；配置接口已实现不代表真实训练已完成。分阶段沿用经三种子复核的配置；通常重新从ImageNet初始化；A0及S3的224对照不得用历史R0冒充已完成。
