# 多标签头、Study MIL 与通用自监督路线评估

核对日期：2026-11-07。研究记录，未修改代码、配置或训练记录，未启动训练。效果建议均为待验证假设。

## 当前工程

- 当前是10标签主头，另有0/3/7三个MLP专家头，是否启用取决于运行配置，并非9标签单线性头。
- StudyDataset把同一Study所有图像共同送入模型；默认attention聚合，已经属于注意力式多实例学习。M3实际是study_pooling=mean，把注意力替换为均值，不是首次引入MIL。
- 当前训练清单18,513个Study：8,509个一图、8,367个两图、1,637个三图以上，多图占54.04%。约46%的Study没有第二个实例供跨图选择。

## Query2Label与ML-Decoder

Query2Label官方实现为可学习的逐标签query，经cross-attention从空间特征图中提取标签相关信息，再分别二分类。官方证据主要为COCO、VOC、NUS-WIDE等多标签任务的mAP，没有证明本比赛困难标签AUC必然增加0.01–0.02。

ML-Decoder是简化decoder加group decoding。官方普通分类代码明确固定query（query_embed.requires_grad_(False)），不能概括为每标签学一个query。默认query数=min(100,num_classes)，所以10标签直接采用默认值恰好有10个query；大类别数时才表现出多标签共享query的压缩优势。

当前工程先对每图作全局池化，丢弃空间布局。要让标签query关注不同区域，必须保留特征图或patch tokens；仅在已经池化的单向量后增加query无法恢复区域信息。建议优先轻量标签条件attention或单层query decoder，保留相同骨干、数据和损失对照。

来源：
- Query2Label论文：https://arxiv.org/abs/2107.10834
- 官方实现与可学习query：https://github.com/SlongLiu/query2labels/blob/main/lib/models/query2label.py
- ML-Decoder论文：https://arxiv.org/abs/2111.12933
- 固定query、默认group数和group decoding源码：https://github.com/Alibaba-MIIL/ML_Decoder/blob/main/src_files/ml_decoder/ml_decoder.py
- 两个代码仓库LICENSE本次均核对为MIT；现成预训练权重的许可仍须单独核验。

## ABMIL与TransMIL

ABMIL在分类前对实例向量做注意力加权；当前Study attention与其核心思路相近，但不一定等同原版gated ABMIL。值得试验的是gated attention、逐标签图像权重或轻量跨图交互。

原版TransMIL面向病理全切片大量patch：官方源码包含补齐方形、PPEG二维卷积位置模块、Nyström attention，示例为6000实例，分类输出为softmax。这里Study通常1–2图，且胸片之间不存在patch网格的二维邻接意义，不能直接照搬；还需处理变长mask、实例顺序和10标签sigmoid/loss。源码硬编码.cuda()，不能原样用于Mac。通用架构思路与其医学预训练权重应分开判断。

来源：
- ABMIL论文：https://arxiv.org/abs/1802.04712
- ABMIL官方代码：https://github.com/AMLab-Amsterdam/AttentionDeepMIL
- TransMIL论文：https://proceedings.neurips.cc/paper/2021/file/10c272d06794d3e5785d5e7c5356e9ff-Paper.pdf
- TransMIL官方源码：https://github.com/szc19990412/TransMIL/blob/main/models/TransMIL.py

## DINOv2、MAE与官方训练集自监督

DINOv2原版公开权重在LVD-142M（1.42亿图）训练，并非仅ImageNet。其官方论文说明为公开网络图像经通用视觉数据集检索筛选；README明确code and model weights采用Apache-2.0。按补充规则的通用主数据来源判定，这是可申报核验的通用候选。须锁定具体原版权重、许可证、主数据说明和SHA-256；同仓库现在也包含XRay-DINO、Cell-DINO等医学变体，不能混用。

原始MAE在ImageNet-1K自监督预训练，但facebookresearch/mae官方README与LICENSE为CC-BY-NC 4.0。比赛明确拒绝NC许可证，因此不能直接把其官方MAE公开权重当合规候选。MAE思想与具体权重不同；可找独立可核验、允许再分发的非NC实现和权重，或以已合规初始化在官方训练集自行实现掩码自监督。MAE原版是ViT体系，不能把其权重直接载入ConvNeXt。

## 建议顺序

1. 优先轻量按标签attention/query头，检验空间和跨图选择机制。
2. 原版通用DINOv2 ViT-B/14作为不同特征来源候选，先核来源与许可、单种子筛选，再补42/2027/3407。
3. 官方训练集自监督是允许但成本更高的研究路线，保留同初始化直接有监督微调对照，固定预训练预算。
4. 原版TransMIL优先级低于轻量标签条件聚合，当前工程并不缺Study级训练。

比较同数据、纯图像协议下的三种子macro AUC、逐标签AUC和患者级bootstrap不确定性，同时核算最终推理大小与耗时。不承诺未经本项目实验验证的0.01–0.02提升。
